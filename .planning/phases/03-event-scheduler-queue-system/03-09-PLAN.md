**Integration Architecture:**
```
/trigger endpoint
    |
    +-> Initialize Scheduler (once at startup)
    |       - VirtualClock with tick_duration_hours from settings
    |       - ScheduledActionStore for SQLite persistence
    |
    +-> Initialize SprintPlanner (once at startup)
    |       - Uses Scheduler for action scheduling
    |
    +-> Each tick:
            1. sprint_planner.check_and_plan() - maintain horizon
            2. tick_executor.execute_tick() - run due actions
            3. scheduler.advance_tick() - advance simulation time
```
