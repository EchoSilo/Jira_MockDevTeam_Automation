- src/orchestrator/orchestrator.py: ScenarioOrchestrator._execute_action is ASYNC

**Critical Architecture Decisions (Revision 2):**

1. **Async/Sync Bridge:** TickExecutor.execute_tick() is SYNC, but orchestrator._execute_action() is ASYNC.
   Solution: Use `asyncio.run()` in callback wrapper to bridge sync->async.

2. **Single Execution Path (EXEC-01 compliance):** EXEC-01 says TickExecutor REPLACES orchestrator execution.
   Solution: Add `skip_execution` parameter to orchestrator.run_tick() that skips Phase 3 (Execute) loop.
   - orchestrator.run_tick(skip_execution=True) handles Analyze + Plan only
   - TickExecutor.execute_tick() handles scheduled action execution
   - NO DUAL EXECUTION - actions execute exactly once

**Integration Architecture:**
```
/trigger endpoint
    |
    +-> Initialize Scheduler (once at startup)
    |       - VirtualClock with tick_duration_hours from settings
    |       - ScheduledActionStore for SQLite persistence
    |
    +-> Initialize SprintPlanner (once at startup)
    |       - Uses Scheduler for action scheduling
    |
    +-> Each tick:
            1. sprint_planner.check_and_plan() - maintain horizon
            2. orchestrator.run_tick(skip_execution=True) - analyze + plan only
            3. tick_executor.execute_tick() - run due actions (SOLE EXECUTOR)
            4. scheduler.advance_tick() - advance simulation time
```
