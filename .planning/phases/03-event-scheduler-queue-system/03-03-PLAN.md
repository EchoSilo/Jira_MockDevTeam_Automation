<feature>
  <name>BusinessHoursScheduler (TDD)</name>
  <files>src/scheduling/business_hours.py, tests/test_scheduling_business_hours.py</files>
  <behavior>
    BusinessHoursScheduler class:
    - work_start_hour: int = 9
    - work_end_hour: int = 17
    - timezone: str = "America/New_York"

    Methods:
    1. is_business_day(dt: pendulum.DateTime) -> bool:
       - Return dt.day_of_week < 5 (Mon=0 to Fri=4 in Pendulum)
       - Note: Pendulum uses 0-indexed (0=Monday, 6=Sunday)

    2. is_business_hours(dt: pendulum.DateTime) -> bool:
       - Return is_business_day(dt) AND work_start_hour <= dt.hour < work_end_hour

    3. next_business_day(dt: pendulum.DateTime) -> pendulum.DateTime:
       - Move to next day at work_start_hour
       - Skip weekends
       - Return Monday 9am if dt is Friday/Saturday/Sunday

    4. schedule_action(base_time: pendulum.DateTime, hours_from_now: float) -> pendulum.DateTime:
       - Calculate target_time = base_time + hours
       - If target_time on weekend: move to Monday 9am
       - If target_time before work_start_hour: move to same day work_start_hour
       - If target_time >= work_end_hour: move to next_business_day

    Test cases:
    - is_business_day(Monday) -> True
    - is_business_day(Saturday) -> False
    - is_business_day(Sunday) -> False
    - is_business_hours(Monday 10am) -> True
    - is_business_hours(Monday 6pm) -> False
    - is_business_hours(Saturday 10am) -> False
    - next_business_day(Friday) -> Monday 9am
    - next_business_day(Monday) -> Tuesday 9am
    - schedule_action(Friday 4pm, 2 hours) -> Monday 9am (not Saturday)
    - schedule_action(Monday 6pm, 0 hours) -> Tuesday 9am
    - schedule_action(Monday 8am, 0 hours) -> Monday 9am (before work hours)
    - schedule_action(Monday 10am, 2 hours) -> Monday 12pm (within hours)
  </behavior>
  <implementation>
    Use Pendulum for all datetime operations. Pendulum's day_of_week is 0=Monday through 6=Sunday.

    For schedule_action, chain checks:
    1. Add hours to base_time
    2. If not business day, call next_business_day
    3. If hour < start_hour, set to start_hour same day
    4. If hour >= end_hour, call next_business_day

    Handle timezone by converting to local timezone for hour checks,
    but return times in original timezone.
  </implementation>
</feature>
