<feature>
  <name>VirtualClock for Simulation Time (TDD)</name>
  <files>src/scheduling/virtual_clock.py, tests/test_scenario_scheduler.py</files>
  <behavior>
    VirtualClock class:
    - _simulation_time: pendulum.DateTime
    - tick_duration_hours: float = 0.75 (45 minutes, matches n8n cadence)

    Methods:
    1. __init__(start_time: pendulum.DateTime, tick_duration_hours: float = 0.75)
    2. now() -> pendulum.DateTime: Return current simulation time
    3. advance(hours: Optional[float] = None) -> pendulum.DateTime:
       - Add hours (default: tick_duration_hours) to simulation_time
       - Return new simulation_time
    4. set_time(time: pendulum.DateTime) -> None: Jump to specific time

    Test cases:
    - now() returns simulation_time
    - advance() adds tick_duration_hours (default 0.75)
    - advance(hours=2) adds 2 hours
    - set_time() jumps to specific time
  </behavior>
  <implementation>
    Simple wrapper around pendulum.DateTime with add() for advancement.
    Simulation time is independent of real wall-clock time.
  </implementation>
</feature>

<feature>
  <name>ScenarioScheduler (TDD)</name>
  <files>src/planning/scenario_scheduler.py, tests/test_scenario_scheduler.py</files>
  <behavior>
    ScenarioScheduler class:
    - business_hours: BusinessHoursScheduler

    Methods:
    1. __init__(business_hours: Optional[BusinessHoursScheduler] = None)
       - Use provided or create default BusinessHoursScheduler

    2. convert_scenario_to_actions(
         scenario_script: List[dict],
         sprint_start_date: pendulum.DateTime,
         ticket_key: str,
         scenario_id: str
       ) -> List[ScheduledAction]:
       - For each script action with "day" field (1-7):
         a. Calculate base_date = sprint_start_date + (day - 1) days
         b. If base_date is weekend, move to Monday
         c. Add random offset within business hours (0-8 hours)
         d. Create ScheduledAction with calculated timestamp
       - Return list of ScheduledActions

    3. _distribute_time_within_day(
         base_date: pendulum.DateTime
       ) -> pendulum.DateTime:
       - Add random hours (0-8) to distribute throughout workday
       - Add random minutes (0-59) for realistic timestamps
       - Use business_hours.schedule_action() to ensure valid time

    Script action format:
    {
        "day": 1,       # Day of sprint (1-7)
        "type": "pick_up_task",
        "agent_id": "dev_alpha_1",
        "expected_status": "To Do",
        "params": {}
    }

    Test cases:
    - Day 1 action gets sprint_start_date (Wednesday)
    - Day 3 action gets sprint_start_date + 2 days (Friday)
    - Day 6 action on Saturday gets moved to Monday
    - Actions have randomized times (not all :00:00)
    - All actions have valid business hours timestamps
    - 7 script days produce 5 scheduled days (weekends skipped)
  </behavior>
  <implementation>
    Use random.uniform(0, 8) for hour distribution within 9-5.
    Use random.randint(0, 59) for minute variation.
    Chain with business_hours.schedule_action() to ensure valid times.

    Handle edge case: If sprint starts Wednesday and script has day 6,
    that's Monday of next week (Wed+5 = Mon after weekend).
  </implementation>
</feature>
