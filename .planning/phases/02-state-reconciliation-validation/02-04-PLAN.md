<task type="auto">
  <name>Task 2: Create circuit breaker wrapper</name>
  <files>src/reconciliation/circuit_breaker.py</files>
  <action>
    Create ResilientJiraClient that wraps JiraClient with circuit breaker protection.

    Two separate breakers (per research recommendations):
    - jira_read_breaker: fail_max=5, timeout_duration=60, for read operations (get_issue, etc.)
    - jira_write_breaker: fail_max=3, timeout_duration=120, more sensitive for writes (transition_issue, etc.)

    Implementation:
    ```python
    from pybreaker import CircuitBreaker, CircuitBreakerListener, CircuitBreakerError
    import logging

    logger = logging.getLogger(__name__)

    class LoggingCircuitBreakerListener(CircuitBreakerListener):
        def state_change(self, cb, old_state, new_state):
            logger.warning(f"Circuit breaker '{cb.name}' changed from {old_state.name} to {new_state.name}")

        def failure(self, cb, exc):
            logger.debug(f"Circuit breaker '{cb.name}' recorded failure: {exc}")

        def success(self, cb):
            logger.debug(f"Circuit breaker '{cb.name}' recorded success")

    jira_read_breaker = CircuitBreaker(
        fail_max=5,
        timeout_duration=60,
        name="jira_reads",
        listeners=[LoggingCircuitBreakerListener()]
    )

    jira_write_breaker = CircuitBreaker(
        fail_max=3,
        timeout_duration=120,
        name="jira_writes",
        listeners=[LoggingCircuitBreakerListener()]
    )

    class ResilientJiraClient:
        def __init__(self, jira_client: JiraClient):
            self._client = jira_client

        @jira_read_breaker
        def get_issue(self, issue_key: str):
            return self._client.get_issue(issue_key)

        @jira_read_breaker
        def is_issue_in_active_sprint(self, issue_key: str) -> bool:
            return self._client.is_issue_in_active_sprint(issue_key)

        @jira_write_breaker
        def transition_issue(self, issue_key: str, transition_name: str) -> bool:
            return self._client.transition_issue(issue_key, transition_name)

        @jira_write_breaker
        def add_comment(self, issue_key: str, comment: str) -> None:
            return self._client.add_comment(issue_key, comment)

        def get_breaker_state(self) -> dict:
            return {
                "reads": jira_read_breaker.current_state.name,
                "writes": jira_write_breaker.current_state.name
            }

        # Pass-through for non-wrapped methods
        def __getattr__(self, name):
            return getattr(self._client, name)
    ```

    Export CircuitBreakerError for callers to catch circuit-open scenarios:

    __all__ = ["ResilientJiraClient", "jira_read_breaker", "jira_write_breaker", "CircuitBreakerError"]
