  <behavior>
    ExecutionTracker:
    - generate_execution_id("transition_to_in_progress", "ESCRUM-123", "dev_alice") -> "transition_to_in_progress:ESCRUM-123:dev_alice:abc12345"
    - is_executed("transition_to_in_progress:ESCRUM-123:dev_alice:abc12345") -> False (first time)
    - record_execution(execution_id, "transition_to_in_progress", "ESCRUM-123", "success") -> stores record
    - is_executed("transition_to_in_progress:ESCRUM-123:dev_alice:abc12345") -> True (after recording)

    Cleanup behavior:
    - Records older than cleanup_age_hours (default 48) are automatically purged on record_execution()
    - Cleanup runs on each record_execution() call (piggyback pattern)

    ExecutionRecord dataclass:
    - execution_id: str
    - action_type: str
    - ticket_key: str
    - executed_at: pendulum.DateTime
    - result: str  # "success" | "failure" | "skipped"
  </behavior>
  <implementation>
    1. Create src/reconciliation/execution_tracker.py with:

       @dataclass
       class ExecutionRecord:
           execution_id: str
           action_type: str
           ticket_key: str
           executed_at: pendulum.DateTime
           result: str  # "success" | "failure" | "skipped"

       class ExecutionTracker:
           def __init__(self, cleanup_age_hours: int = 48):
               self._executed: dict[str, ExecutionRecord] = {}
               self._cleanup_age = timedelta(hours=cleanup_age_hours)

           def generate_execution_id(self, action_type: str, ticket_key: str, agent_id: str) -> str:
               # Format: {action_type}:{ticket_key}:{agent_id}:{uuid8}
               unique_id = str(uuid.uuid4())[:8]
               return f"{action_type}:{ticket_key}:{agent_id}:{unique_id}"

           def is_executed(self, execution_id: str) -> bool:
               return execution_id in self._executed

           def record_execution(self, execution_id: str, action_type: str, ticket_key: str, result: str) -> None:
               self._executed[execution_id] = ExecutionRecord(...)
               self._cleanup_old_executions()

           def _cleanup_old_executions(self) -> None:
               cutoff = pendulum.now("UTC") - self._cleanup_age
               self._executed = {k: v for k, v in self._executed.items() if v.executed_at > cutoff}

    2. Update src/reconciliation/__init__.py to export ExecutionTracker, ExecutionRecord

    3. Write tests covering:
       - Generate unique execution IDs
       - is_executed returns False for new IDs
       - is_executed returns True after recording
       - Cleanup removes old records (use FakeClock to simulate time passage)
       - Multiple executions with same parameters but different UUIDs are tracked separately
  </implementation>
</feature>
