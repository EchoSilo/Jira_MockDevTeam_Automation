<feature>
  <name>Random Event Generator with Probability Rolling</name>
  <files>src/chaos/event_generator.py, tests/test_event_generator.py</files>
  <behavior>
    RandomEventGenerator class:
    - __init__(config: ChaosConfig, seed: Optional[int] = None)
      - Store config, create random.Random instance (seeded for testing)

    - roll_for_event(current_tickets: list[str], current_agents: list[str]) -> Optional[RandomEvent]
      - If not config.enabled, return None
      - Roll self.rng.random() against config.base_event_chance (e.g., 0.10 = 10%)
      - If roll fails, return None (no event this tick)
      - Filter to enabled events (probability > 0)
      - Use random.choices() with weights to select event type
      - Call _create_event() to build RandomEvent with details
      - Return RandomEvent

    - _create_event(event_type: ChaosEventType, tickets: list[str], agents: list[str]) -> RandomEvent
      - Select affected tickets/agents based on event type:
        - urgent_bug: 1-2 random tickets
        - production_outage: 2-3 random tickets (critical severity)
        - team_absence: 1 random agent, duration_ticks=2-4
        - external_blocker: 1 random ticket
        - priority_shift: 1-2 tickets
        - scope_change: 1 ticket
      - Generate description string for event
      - Return RandomEvent with pendulum.now("UTC") timestamp

    Tests (pytest tests/test_event_generator.py):
    - roll_for_event returns None when disabled
    - roll_for_event returns None when roll exceeds base_event_chance
    - roll_for_event returns event when roll succeeds (seeded for determinism)
    - Zero-probability events never selected (urgent_bug=0.0 never picked)
    - Weighted selection favors higher probabilities over many iterations
    - _create_event generates valid RandomEvent with correct fields
    - team_absence event has duration_ticks > 1
    - production_outage always has severity "critical"
  </behavior>
  <implementation>
    1. Create RandomEventGenerator class with config and seeded rng
    2. Implement roll_for_event() with base chance check + weighted selection
    3. Implement _create_event() with event-specific logic
    4. Use random.choices() from stdlib (not numpy) for weighted selection
    5. Write comprehensive tests with fixed seeds for determinism
  </implementation>
</feature>
