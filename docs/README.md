# Jira Team Simulator Documentation

A multi-agent system that generates realistic development team activity in Jira for productivity analytics testing.

---

## What is this?

The Jira Team Simulator creates authentic-looking development team activity by simulating **9 agents across 2 teams** performing realistic actions:

- Status transitions through your workflow
- Contextual comments generated by AI
- Story and bug creation
- Work time logging
- Team dynamics: blockers, QA rejections, dependencies

Perfect for testing productivity analytics, dashboards, and workflow automation without waiting for real team data.

## How It Works (30-second version)

```
┌─────────┐     ┌─────────┐     ┌──────────────┐     ┌─────────┐     ┌──────┐
│  n8n    │────▶│ FastAPI │────▶│ Orchestrator │────▶│ CrewAI  │────▶│ Jira │
│ (cron)  │     │  /trigger│    │  (AI plans)  │     │ (agents)│     │ API  │
└─────────┘     └─────────┘     └──────────────┘     └─────────┘     └──────┘
                                       │
                                       ▼
                                 ┌──────────┐
                                 │  State   │
                                 │ (JSON)   │
                                 └──────────┘
```

1. **Trigger** - n8n calls `/trigger` every ~45 minutes (weekdays 9-5)
2. **Analyze** - System examines your Jira board state
3. **Plan** - AI decides which actions create realistic patterns
4. **Execute** - Agents perform actions via Jira API
5. **Persist** - State is saved for continuity

## Key Concepts

| Concept | Description |
|---------|-------------|
| **Tick** | One simulation cycle (triggered via API) |
| **Intensity** | Activity level: light (1-2 actions), normal (2-4), busy (4-6) |
| **Scenario** | A ticket's journey with optional complications (blockers, rework) |
| **Phase** | Current state in a scenario (e.g., IN_PROGRESS, IN_REVIEW) |
| **Persona** | Agent's personality affecting comment style |

## Cost Estimation

| Component | Estimated Cost |
|-----------|----------------|
| LLM (Anthropic) | ~$0.30-0.50/day |
| Jira | Free tier (10 users) |
| Infrastructure | Docker on local machine |

The system uses cost optimization:
- **Haiku** (fast/cheap) for routine comments
- **Sonnet** (slower/smarter) for complex decisions
- **Templates** for simple status updates (no LLM)
